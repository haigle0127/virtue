Type: GET

Author: haigle

Content-Type: application/x-www-form-urlencoded

Description: 获取路由信息

根据当前登录用户ID获取其权限范围内的菜单路由配置

Request-example:

Response-fields:

Field Type Description Since Example

array

No comments found.

-

-

└─path

string

路由地址

-

└─hidden

boolean

是否隐藏路由，当设置 true 的时候该路由不会再侧边栏出现

-

true

└─redirect

string

重定向地址，当设置 noRedirect 的时候该路由在面包屑导航中不可被点击

-

└─component

string

组件地址

-

└─param

string

路由参数：如 {"id": 1, "name": "小明"}

-

└─alwaysShow

boolean

当你一个路由下面的 children 声明的路由大于1个时，自动会变成嵌套的模式--如组件页面

-

true

└─meta

object

其他元素

-

     └─title

string

设置该路由在侧边栏和面包屑中展示的名字

-

     └─icon

string

置该路由的图标，对应路径src/assets/icons/svg

-

     └─noCache

boolean

设置为true，则不会被 <keep-alive>缓存

-

true

     └─link

string

内链地址（http(s)://开头）

-

└─children

array

子路由

-
